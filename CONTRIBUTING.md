# Beitragen zu Open PC

Danke, dass du bei Open PC mitmachen möchtest! 🎉 Egal ob du Modelle verbesserst, Audios aufnimmst oder Bugs meldest – jede Hilfe ist willkommen.

## 🐛 Issues & Fehler melden
- Beschreibe das Problem so genau wie möglich.
- **Wichtig für 3D-Modelle:** Füge bei Fehlern bitte immer Screenshots oder STL-Previews bei.

---

## 🛠️ Eigene Änderungen einreichen (Pull Requests)

Wir nutzen den klassischen Fork-and-Pull-Workflow. 

1. **Forke** das Repository und klone es.
2. **Branch erstellen:** `git checkout -b feature/dein-feature`
3. **Committen:** Wir nutzen [Conventional Commits](https://www.conventionalcommits.org/):
   * `feat:` Neue Funktion / neues Modell
   * `fix:` Bugfix / Modellfehler behoben
   * `docs:` Dokumentation aktualisiert
   * `chore:` Wartungsarbeiten
4. **Pushen & PR öffnen:** Öffne einen Pull Request gegen den `main`-Branch. Ein Maintainer wird deinen Code prüfen und freigeben.

---

## 🖨️ Vorgaben für 3D-Modelle
Damit die Modelle für alle leicht zu drucken und zu bearbeiten sind, beachte bitte:
- **Dateiformate:** Reiche immer das fertige Druckformat (`.stl` oder `.3mf`) **und** eine universelle CAD-Datei (`.step`) ein. Optional gerne auch die native Projektdatei (z.B. `.f3d` oder `.blend`).
- **Druckbarkeit:** Modelle sollten idealerweise **ohne Supports** druckbar sein (falls möglich).
- **Stabilität:** Wandstärke und genaue Toleranzen: **[Werden nach den ersten Testdrucken noch definiert]**

## 🔊 Vorgaben für Tiptoi-Inhalte
- **Audio:** Das genaue Audioformat (Bitrate/Frequenz) wird aktuell noch getestet und **[hier bald ergänzt]**.
- **Skripte:** Dokumentiere den Code sauber mit Kommentaren, damit andere die Logik nachvollziehen können.
